# Md Rashedul Islam — Research & Professional Website

A free static research portfolio designed for GitHub Pages.

## Before publishing

1. Open `index.html` and replace `YOUR-EMAIL@example.com` with your professional email.
2. Replace the placeholder `#` links in the Professional Profiles section with your Google Scholar, ORCID, LinkedIn, and ResearchGate URLs.
3. Add the DOI/journal webpage link for your publication.
4. Add or update publications, citations, projects, presentations, and professional evidence as appropriate.
5. Keep all public claims factual and verifiable.

## Free publishing with GitHub Pages

1. Create a GitHub account if you do not already have one.
2. Create a new public repository named `yourusername.github.io`.
3. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
4. In GitHub, open **Settings → Pages** and select **Deploy from a branch** if required.
5. Select the `main` branch and `/root`, then save.
6. Your site will use the address `https://yourusername.github.io/`.

You can also use any free static-site host that accepts HTML/CSS/JavaScript.
